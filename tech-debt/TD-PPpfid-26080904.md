*Filed 2026-08-09, from the 2026-08-08 project review (R-05, F-DEPS-01,
F-CI-03).* Severity: Low. Two small process gaps in this repo's Dependabot
hygiene:

1. PR #129 (`eslint` 9.39.5 → 10.8.0), opened 2026-07-26, is permanently
   `mergeable: CONFLICTING` — `eslint-config-next` still calls the
   ESLint-10-removed `context.getFilename()`, so no `eslint-config-next`
   release accepts ESLint 10 yet (documented in
   `tech-debt/TD-PPpfid-26072429.md`'s root-cause entry). `.github/dependabot.yml`
   has `ignore: version-update:semver-major` rules for the two other
   documented, genuinely-blocked majors (`jsdom`, `typescript`) but not for
   `eslint`, so this PR will keep re-appearing as unresolved Dependabot
   noise every week.
2. PR #170 (`github/codeql-action` 4 → 4.37.3), opened 2026-08-01, is
   `mergeable: MERGEABLE` with every check green, but has sat unmerged for
   over a week — the one visible outlier against an otherwise same-day
   merge cadence for Dependabot PRs on the `npm` ecosystem. Possibly the
   `github-actions` ecosystem falls outside whatever dispatches the `npm`
   ecosystem's prompt merges.

Fix: add an `eslint` `semver-major` `ignore` rule to `dependabot.yml`
(referencing `tech-debt/TD-PPpfid-26072429.md` in a comment, matching the
`jsdom`/`typescript` entries) and close PR #129; merge PR #170 once
rebased, or confirm whatever normally merges Dependabot PRs promptly also
covers the `github-actions` ecosystem. See
`reviews/project-review-2026-08-08/04-improvement-prompts.md` R-05.
