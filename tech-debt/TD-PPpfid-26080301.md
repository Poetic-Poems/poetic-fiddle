*Filed 2026-08-03, from the review of PR #186 (TD-PPpfid-26073101).*
`supabase/config.toml` configures the local Supabase stack that `supabase
start` brings up for `npm run test:db`. The `deploy` job in
`.github/workflows/ci.yml` runs `supabase db push`, which applies
`supabase/migrations` and nothing else — so every non-migration setting in
that file, the whole `[auth]` block included, describes the local stack
only. The live project's equivalents are dashboard settings that no commit
here can change, and nothing detects when the two disagree.

TD-PPpfid-26073101 is where this first bit: raising
`minimum_password_length` to 10 in `config.toml` closed the gap for local
development and left the live project still accepting six-character
passwords through a direct Supabase Auth call, until a maintainer sets the
same minimum in the dashboard by hand. PR #186 asks for that manually in a
comment, which is exactly the kind of out-of-band step this item exists to
replace.

Fix: decide how the live project's auth configuration is governed, and make
the answer checkable. Two shapes are worth evaluating:

- Push it. The Supabase CLI can apply non-migration config to a linked
  project, so CI could apply `config.toml` on a merge to `main` the way it
  already applies migrations. The caveat to settle first is blast radius:
  such a push applies the file as a whole, and this file carries local-stack
  values (`site_url`, redirect URLs, SMTP, OAuth providers) that must not
  overwrite the live project's. That likely needs the deployable settings
  separated from the local-only ones, or environment substitution, before it
  is safe.
- Assert it. A scheduled or pre-deploy check that reads the live project's
  auth settings through the Management API and fails when they drift from
  the committed ones — the same shape as
  `.github/workflows/required-checks-drift.yml`. This leaves the dashboard
  authoritative but stops drift being invisible.

Either way the immediate consequence to close is a documented, verified
minimum password length of 10 on the live project.
