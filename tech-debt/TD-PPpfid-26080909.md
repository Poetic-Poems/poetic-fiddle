*Filed 2026-08-09, from the 2026-08-08 project review (R-10, F-ARCH-02).*
Severity: Low. `wirePoemToggles` and `evaluatePostscriptPreviews`
(`src/components/PoemPreview.tsx:24-159`) are pure DOM manipulation with no
JSX/React dependency, yet the file is a `"use client"` component;
`src/components/SharedPoemView.tsx:4-8` imports both cross-component. This
is the same finding the 2026-07-31 project review filed (then named
`wireAnalysisToggles`, R-14: "move to `src/lib/` next time either caller is
touched"). Both callers have since been touched (PRs #172, #194, #202,
#216), but the move was never made, and — unlike that review's other
findings — no tech-debt record existed for it, so it stayed invisible to
an agent checking the register before touching this code again. It works
today and both call sites document the coupling, but it's the one place a
`components/` file depends on another `components/` file for logic.

Fix: move `wirePoemToggles`/`evaluatePostscriptPreviews` to
`src/lib/poem-toggles.ts` (a small, mechanical change with existing test
coverage to carry across). See
`reviews/project-review-2026-08-08/04-improvement-prompts.md` R-10.
